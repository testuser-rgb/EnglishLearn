考纲范围与高频考点速查表

依据 《江苏省高等学历继续教育学士学位英语考试大纲》（江苏省学位外语官网 2024-06-03 现行版）整理； 考纲要求与题型结构延续未变，报名与考试时间以官网当年公告为准。
适用：江苏高校联盟各成员校（南通大学、苏州大学、江南大学、江苏大学、常州大学、南京师范大学、南京中医药大学等）成人本科学士学位申请。

词汇范围 官方口径：4000 词 + 500 词组

领会式掌握
4000 词
能识别词类、理解词义即可（阅读/完形里"认得"）
领会式词组
500 个
常用固定搭配与短语动词
复用式掌握
2000 词 + 200 词组
会拼写、会搭配、会用于翻译与写作
层级要求考查落点冲刺台里的落点
领会式 4000 词阅读中见词能辨义、辨词性阅读理解、完形填空词库只收 1433 词；其中 D 层 872 词"只求认得"，认满 2 次归档
复用式 2000 词 + 200 词组拼写正确、搭配熟练、语法功能清楚词汇和语法题、汉译英、写作C 层 279 + B 层 151 走复用要求；今日输出 8 句 / 写作 4 篇
关键差异（容易踩坑）：全国版《成人高等教育本科生学士学位英语水平考试大纲》要求 4400 词 + 550 词组，而江苏联盟用的是 4000 词 + 500 词组。买资料时认准"江苏省"版本，不要照搬 4400 词的四级词汇表硬背。
包含中学词汇：大纲明确 4000 词含中学阶段已掌握的基础词，新增部分集中在学术类（analyze、evaluate）与职场类（negotiate、implement）。
与冲刺台的关系：工具内 1433 词是按 60 分过线目标裁剪、并按 9 份真题中高频词校准的子集，不是大纲 4000 词全量； 分层为 A25 / B151 / R106 / C279 / D872，按 280 个词块组安排每天的新词。 复习走 1 / 3 / 7 / 15 / 30 天间隔（D 层 1 / 5 天、认满 2 次即归档），答错的关联词会自动拉回当天背词队列。 遇到"大纲里有、工具没收"的词属正常，可在进度页导入自定义词表。

语法范围：大纲十项 → 实际考频

大纲列的十项是全范围；但 20 道语法题的实际分布高度集中，非谓语动词、各类从句、虚拟语气三项就吃掉近一半语法分。

大纲条目考频高频细分考点典型易错
1. 名词、代词的数和格中频不可数名词、名词所有格、it 作形式主语/宾语、one / that / those 替代information / advice / equipment 不可数
2. 动词时态、语态高频现在完成 vs 过去完成、将来完成、被动语态（含完成被动、情态被动）、时间状语从句中的"主将从现"by the time + 过去完成；since 引导的完成时
3. 形容词、副词比较级最高级中频as…as、the more…the more、比较级修饰语（much / far / even / a lot）、倍数表达、最高级 + in / of 范围superior / inferior / senior 后接 to 不接 than
4. 常用连接词、冠词中频a/an/the 特指泛指与零冠词、both…and / not only…but also / either…or 的主谓一致the + 形容词表一类人；固定搭配中冠词的省略
5. 非谓语动词最高频不定式作目的/结果状语、动名词作主语宾语、介词后必用 doing、分词作定语/状语、having done 与 being done、独立主格逻辑主语与主句主语不一致；be used to doing vs used to do
6. 虚拟语气高频if 虚拟三类（与现在/过去/将来相反）、suggest / demand / insist / order + (should) do、It is important that…、wish / as if / would rather、but for、otherwise错综时间条件句；省略 if 的倒装（Were I…/ Had I…）
7. 各类从句最高频定语从句（that/which/whose/where、介词 + which）、名词性从句（what 作成分 / that 不作成分 / whether）、状语从句（although / in case / now that / as long as）that 与 what 混用；which 指代整句
8. 基本句型中频主谓宾补、there be 句型变体、系动词 + 表语、双宾语、It 句型（It seems that…）there be 与 have 混用
9. 强调句型送分题It is / was + 被强调部分 + that / who；not until 的强调结构强调句与定语从句混淆（去掉 It is…that 看句子是否完整）
10. 常用倒装句送分题否定词开头（Hardly…when、Not until、Never、Little）、Only + 状语前置、so / neither 倒装、as / though 让步倒装Hardly…when 用过去完成 + 一般过去
（附）主谓一致中频together with / as well as 就前原则、the number of vs a number of、the only one of…who就近 vs 就前原则判断错误
结论：语法 10 分（约 10 题）里，第 5、6、7 项合计通常占 5–7 题。时间紧时按 非谓语 → 从句 → 虚拟 → 时态语态 → 倒装/强调 的顺序攻，前四项拿稳即可覆盖语法题 80%。
