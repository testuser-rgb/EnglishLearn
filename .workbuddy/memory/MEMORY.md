- 最大前提（用户反复强调）：**题目必须全部自编**，`试卷练习/` 9 份真题 PDF 只作参考校准（篇幅/题型/题材/词频），绝对不能用原题原句，真题留作考前整卷检验。
- 当前数据规模：1433 词、280 词块组、294 条场景提示、阅读 68 篇平均 323 词、作文范文 127–141 词（≥120 词）。按已学词出题的实现逻辑不可改动。
- 已修（2026-11-15）：**答案位置均衡**（`qview/cv/gv`，完形练习、模考语法、模考完形每 4 题一组 ABCD 各一次且组内打乱；阅读沿用 rq 洗牌）＋ **阅读 253 题共 607 个干扰项等长化**。全选 A／选最长项不再能蒙；旧存档作答记录由 `initState()` 一次性迁移（`S._optv=2`）。
- 仍存的设计问题（用户未要求修）：模考满分随完形空数（10/20）与阅读题数（4/5）在 **60–75** 间浮动，过线阈值固定 56/70；`c1`（D1 首套完形）复现词表为空，不影响做题。

## 题库数据管理（2026-11-15 起）
- 题目、选项、答案、解析、词库、范文全部在 `计划与资料/data/`（01–07.js），是唯一真相源；HTML 只留逻辑与渲染，**必须与 data/ 放同一目录**，双击仍离线可用，拷贝要一起带走。
- `data/manifest.json` 是 650 题答案映射基线（文件/常量 SHA256 + 答案指纹）。改完页面跑 `node 计划与资料/data/verify.js`；页面怎么改都不影响映射；要改题目须先确认再重建基线。
- 校验口径：答案指纹只在「只加载数据文件」的纯净环境复算。运行时 LESSONS 会被 BANK_X 合并、rq() 会给题目加 `_o/_a`，拿运行时对象当基线会误报。
- `data/rebuild-baseline.js` 是确认改动题目/文案后的基线重建工具（会追加 `baselineHistory`）；2026-11-15 已按等长化改写与文案校订全量重建，`verify.js` 全绿。**正确选项内容与答案下标始终逐字未动。**
- 文档口径：README + 两份 HTML 说明文档于 2026-11-15 清除全部旧方案/历史口径描述，只保留最终方案；工具内残留的 100 词、54 题、5 句、精读真题、分层旧数字也已一并校订。
