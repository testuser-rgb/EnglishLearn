# 英语学习资料库（江苏联盟学位英语备考）

本目录为江苏联盟学位英语备考的全部学习资料，使用 git 管理。

## 目录说明

- `计划与资料/` — 学习计划与学习工具
  - `江苏联盟学位英语_考纲范围与高频考点速查表.html` — 官方大纲范围（词汇 4000+500 / 语法十项）与高频考点考频表，可打印
  - `学位英语_两个半月过线计划.html` — 8 周 / 每天约 130 分钟的过线计划：切-抓-挂翻译法、8 周地图、1364 词分层、每日流程
  - `学位英语_55天冲刺台.html` — 单文件离线学习工具（双击浏览器打开即可）：
    - 今日任务（每天五件事打卡）
    - 背词（441 词分层词库 + 词根拆解 + 趣记 + 自建记忆）
    - 课堂（10 个知识点课文 + 132 道练习题 + 换新一批 + 到期混排复习）
    - 拆句器 / 句子本 / 进度打卡 / 计划 / 速查
- `试卷练习/` — 试卷与练习材料

## 使用说明

- 学习工具 `学位英语_55天冲刺台.html` 为纯本地网页，数据存浏览器 localStorage，无需联网、无需安装。
- 每天打开工具按「今日」页流程执行即可。
