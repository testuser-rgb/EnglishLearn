# 英语学习资料库（江苏联盟学位英语备考）

本目录为江苏联盟学位英语备考的全部学习资料，使用 git 管理。全部内容本地离线；核心是网页工具 `学位英语_55天冲刺台.html` 与同目录下的 `data/` 题库数据文件夹，**两者必须放在一起**。

## 目录说明

- `计划与资料/`
  - `学位英语_55天冲刺台.html` — **核心学习工具**：双击浏览器打开即用，学习记录存浏览器 localStorage；页面只保留逻辑与渲染，不含题目
  - `data/` — **题库与词库数据**：7 个 `.js` 数据文件（按 `01`→`07` 顺序加载）、`manifest.json` 答案映射基线、`verify.js` 校验脚本、`rebuild-baseline.js` 基线重建脚本。题目、选项、正确答案、解析、词库、范文全部只存这里
  - `学位英语_两个半月过线计划.html` — 文件名沿用旧称，内容是**当前最终版本方案的系统说明与使用约定**：55 天三阶段、每日任务配比、词库/题库机制、选项防蒙题、完成判定、三条使用约束、已知边界
  - `江苏联盟学位英语_考纲范围与高频考点速查表.html` — 官方大纲范围（4000 词 + 500 词组 / 语法十项）、整卷结构、考点考频，可打印
- `试卷练习/` — 9 份历年试卷 PDF。**未接入工具**，仅作补充材料（见「已知边界」）

## 工具概貌

- **周期**：55 天 / 8 周，无休整日。每日 128′（D1–42）→ 145′（D43–52）→ 140′（D53–54）→ 115′（D55），总学时约 120 小时
- **导航动线**：今日 → 背词 → 课堂 → 每日一读 → 完形 → 快练 → 句子本 → 写作 → 实战 → 进度（另有篇目库、考前速查）
- **数据规模**：词库 1433（A25 / B151 / R106 / C279 / D872）· 课堂 L0–L10 共 11 课 140 题 · 阅读 68 篇 278 题（正文平均 323 词，贴近真题篇幅） · 完形 12 套 160 空 · 汉译英题库 404 句 · 长难句 40 · 仿写 18 · 作文 4 篇（范文 127–141 词） · 词块组 280 · 生词中文提示 294
- **阶段解锁**：D43 开写作与限时做题，D53–54 开整卷实战，D55 只复盘；全部按日历天数推进
- **完成判定**：在背词 / 课堂 / 每日一读 / 完形 / 句子本 / 写作 / 实战各页顶部点「学完了，标记完成」，**再点一次即取消**；系统同时显示按真实学习记录算出的进度（仅供参考，不自动打勾）。「今日」页为只读，状态自动同步
- **选项防蒙题**：完形练习、模考词汇语法、模考完形的选项按确定性规则重排，每 4 题一组 A/B/C/D 各占一次且组内顺序打乱；阅读按「篇号＋题号」确定性洗牌，四个位置各约 25%。阅读 253 题共 607 个干扰项已等长化，四项字数接近，正确项不再是最长项（选最长命中率由 77.3% 降至 19.8%）。全选 A 或按 ABCD 规律选的期望命中率约 25%（单卷会波动）。旧存档里已作答的完形／模考记录会在打开时自动换算到新位置，不丢分

## 使用说明

- 纯本地网页，无需联网或安装。**打开 `学位英语_55天冲刺台.html` 时必须与 `data/` 文件夹同目录**；少一个数据文件页面会显示红色提示。拷贝或移动时要把 HTML 和文件夹一起带走。
- 学习记录只存在**当前浏览器**的 localStorage：换浏览器、换设备、清缓存都会丢，工具**没有导出/备份存档功能**；进度页可「导入自定义词表」和「清空全部学习记录」。
- 进度页「计划起始日」决定第几天，改它会重算天数、打卡记录保留；不填则按首次打开当天算第 1 天。
- 每天按左侧导航从上往下走，学完一项就在该页顶部标记完成。

## 题库数据管理

- 26 个数据常量（词库、阅读、完形、语法题库、动态出题器、作文范文等）已从 HTML 抽出到 `data/*.js`，HTML 里对应位置只留一行来源注释。**数据文件是唯一真相源，页面只留逻辑与渲染。**
- 2026-11-15 对数据做过两次收口：① 阅读 253 题共 607 个干扰项等长化改写（只补细节、向正确项字数靠拢）；② 阶段目标词量、作文 120 词、任务文案按最终方案校订。**两次都没有改正确选项内容与答案下标。**
- `data/manifest.json` 是当前基线：每个文件、每个常量的 SHA256，以及 650 道题（阅读 278 / 完形 160 / 语法 140+72）的答案映射指纹；`baselineHistory` 记录了基线的变更原因。
- 页面改版后运行 `node 计划与资料/data/verify.js`：检查数据文件是否被改动、答案下标是否越界、映射是否与基线一致。**改页面不会碰到题目与答案**；若确需改题，先确认改动，运行 `node 计划与资料/data/rebuild-baseline.js` 重建基线，再跑 `verify.js` 校验。

## 三条使用约束（务必遵守）

1. **不能拖词量**：阅读和完形按 `dayNum()` 日历解锁，运行时不检查你实际背了哪些词。落后时先把到期复习清完、把欠的新词补齐，再往后读。
2. **按天预设，不是自适应**：每篇阅读 / 每套完形写死了一组「该天应已学过」的复现词表，不跟随实际掌握记录。
3. **遇到没学过的词是正常的**：正文不是封闭词表，靠上下文和页面给的中文提示处理；词库外的词答错**不会自动进背词队列**，觉得重要要手动加词。

## 已知边界

- **题源全部自编**：工具内题目为手写原创、只用真题作参考校准（篇幅、题型、题材、词频），不使用真题原句或原题；9 份真题没有进入学习闭环，留作考前整卷检验。词库按 9 份真题中高频词补足 69 个考点词，阅读正文按真题篇幅扩写、作文范文按真题 120 词要求重写。数据统一存 `data/`，与页面逻辑分离。
- **模考不是全真卷**：D53–54 实战是标称 70 分的客观题卷（20 词汇语法 + 1 套完形 + 2 篇阅读 / 90 分钟），不含汉译英和作文；按 56/70 显示「已过线（客观题版）」，不能代替 100 分卷的 60 分验证。因完形套有 10 / 20 空、阅读篇有 4 / 5 题，**实际满分会在 60–75 间浮动**，阈值不随之调整，系统内分数只用来看练没练。
- **手写译文 / 精读五步法没有对应功能**：每日一读是四选一，句子本要自己粘句子且无参考译文；「看懂句子」这条主线需自己加做（把句子用中文说一遍）。
- **无前后测**：进度页模考分数为手填，工具内没有起点摸底与阶段对比，「提分效果」需自行记录。
- **里程碑无门槛**：每周验收文字、8 周地图、里程碑勾选仅作展示，不会因未达标阻断下一阶段。
