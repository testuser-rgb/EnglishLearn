系统是什么 页面 + 数据文件夹 · 离线 · 本地存档

运行方式

  • HTML 页面 + data/ 文件夹：双击 HTML 用浏览器打开，无需联网、无需安装、无需服务器；两者必须放在同一目录，拷贝时一起带走，缺文件页面会给红色提示。
  • 题目与答案只在 data/*.js：页面只留逻辑与渲染，后续怎么改版都碰不到题目和正确答案的对应关系。改版后可在命令行运行 node 计划与资料/data/verify.js 核对答案映射基线。
  • 数据存 localStorage：学习记录只存在当前浏览器。换浏览器、换设备、清缓存都会丢失；工具没有导出/备份存档功能。
  • 进度页可设置计划起始日（决定第几天，改它会重算天数、打卡记录保留）、导入自定义词表、手填模考成绩、清空全部记录。
  • 用浏览器打印即可；各学习页顶部的完成条在打印时会自动隐藏。

导航动线（按学习顺序排）

  • 今日 → 背词 → 课堂 → 每日一读 → 完形 → 快练 → 句子本 → 写作 → 实战 → 进度
  • 另有「篇目库」和「考前速查」两个入口。
  • 写作 D43 解锁、实战 D53 解锁；未解锁的点了会提示还差几天，不会静默无反应。
  • 今日页是只读看板：显示完成度与各项状态，不接收勾选。

大纲要求 4000 词 + 500 词组；工具只收 1433 个精准分层的词，并按层决定是否要求"会写"。

层数量新词配比定位与掌握标准

每天背多少，系统自己算

  • 渐进起步：D1 20 → D2 24 → D3 28 → D4 起 30；第 8 周上限 22。
  • 看复习欠账降量：到期 >110 张降到 22，>80 张降到 26；连续 3 天还不清，当天新词为 0，只还账。
  • 单轮复习卡上限 120 张，避免一轮拖成一小时。
  • 新词按 280 个词块组和层配比动态挑，学了一半的组下次优先收尾。

复习与回炉

  • R/C/B/A 层走 5 档间隔 1 / 3 / 7 / 15 / 30 天；D 层只走 1 / 5 天，认满 2 次归档。
  • 词卡按"认识 / 模糊 / 不认识"三档判分，不认识的词降 box、当天最多再出现一次。
  • 答错自动回炉：阅读、完形、课堂里答错的关联词会被 markWeak() 降 box、due 拉回今天。
  • 例外：词库外 / 还没学过的词答错不会进背词队列（被 seen 挡住），要手动加词。
唯一的"硬衔接"：快练只从"已学过（seen）"的词里出题，句子练习只挖含 1–2 个已学词的句子； 阅读和完形则是按天预设词表，不查真实掌握记录（见第 11 节）。

每日一读与完形：按天解锁、难度自适应

每日一读（68 篇 / 278 题 · 正文平均 323 词）

  • 解锁条件只有一条：篇目.d ≤ 今天。不限篇数、不限次数，随时能读。
  • 今日推荐 = 难度最接近当前水平的那篇；目标难度 28 + 天数 × 1.08（D1≈29、D20≈50、D40≈71、D55≈87）。
  • 四选一 + 逐题解析，答错关联词自动回炉背词队列。
  • 选项防蒙题：干扰项按正确项长度补齐细节，四项字数接近，正确项不再是最长项；顺序按「篇号＋题号」确定性洗牌，A/B/C/D 各约 25%。
  • 每篇标了一组约 22 个"刻意复现"的已学词，但正文不是封闭词表（平均 189 个去重词）。

完形填空（12 套 / 160 空）

  • 同样按 套.d ≤ 今天 解锁；交卷后本套不能再改，逐空给解析。
  • 选项按确定性规则重排：每 4 空一组 A/B/C/D 各一次、组内顺序打乱，全选 A 期望约 25%；练习页与模考页同一空顺序一致。
  • 完形选项多数不是词库原形，靠词形变化、基础词和 294 条中文提示兜底；正文里有少量词库外场景词属正常。
正文不是封闭词表：阅读与完形按天预设一组要复现的已学词，正文允许少量生词并给中文兜底； 运行时不校验你实际背过哪些词，遇到没学过的词属正常。
7

快练 / 句子本 / 今日输出

模块实际做法
快练题量无上限，全部用已学过的词现算；只挖含 1–2 个已学词的句子。不计入今日任务清单，属于加练。
今日输出固定 8 句汉译英：2 句当周长难句 + 3 句今天新词/最近学过的词 + 2 句今天回炉/最近碰过的词 + 1 句仿写，不足由 404 句题库按日固定抽样补齐。每句有输入框 + 可折叠参考译文。
拆句器并进「句子本」：要自己粘一句英文进来，填切意群 / 抓主干 / 写译文，再按三类错因（词不认识 · 结构看错 · 中文不顺）归因。没有内置参考译文，对错只能自己判断或贴给 AI。
句子本收录自建句子与归因记录，可筛选回看。
今日输出是中译英（看中文写英文）；工具不承载英译中的手写精读流程，想练需自己拿真题段落加做（见第 12 节）。

整卷实战：D53 起，标称 70 分客观题卷

项目实际内容
组卷20 道词汇语法 + 1 套完形 + 2 篇阅读（最多 48 题），按当前难度从已解锁篇目里抽；标称 70 分
满分浮动完形套有 10 / 20 空、阅读篇有 4 / 5 题，因此实际满分在 60–75 之间浮动；过线阈值固定按 56/70，不随卷调整。系统内分数只用来看练没练
选项词汇语法与完形按确定性规则重排，每 4 题一组 A/B/C/D 各占一次；阅读按篇号＋题号洗牌。全选 A 或按 ABCD 规律选的期望命中率约 25%
计时90 分钟倒计时，到点自动交卷；交卷后不可再改
反馈分段成绩（词汇语法 / 完形 / 阅读）、全卷错题解析、最近 20 卷历史
判定按 56/70 显示「已过线（60 分及格线下的客观题版）」，阈值不随实际满分调整
缺少汉译英 5 句（15 分）和作文（15 分）没有进模考
这意味着：同一段 90 分钟里少做了 30 分的产出题，时间压力被明显低估；工具内无法验证"整套 100 分卷 90 分钟 ≥60 分"。 考前务必自己拿 试卷练习/ 里的真题整卷掐表做一次，把翻译和作文补上。

完成判定：在学习现场点，随时可取消

「今日」页只是看板，不能勾选。完成与否在每个学习页顶部的完成条里判定，状态与今日页共用同一份按天记录。

动作结果
点「○ 学完了，标记完成」该项记为已完成，按钮变「✓ 已完成 · 点击取消」，并记录在哪一页、几点标记
再点一次回到未完成，来源与时间清掉
系统进度提示按钮旁显示按真实记录算出的「已达标 / 未达标」与具体数字，仅供参考，不自动打勾、不锁死
今日页只读同步：显示勾选状态与「在 X 页标记 · HH:MM」，未完成项提示该去哪一页点
存储S.days[日期][任务号]，按天隔离，刷新不丢；跨天互不干扰
系统的"识别"做到哪一步：进度提示全部读真实数据——到期词剩余张数、今天新学 n/目标、本周课已学几课、 本篇已答 n/N 题 / 本套已填 n/N 空、今日输出已写句数、作文字数与自查条数、今天是否交过卷。 但判定权留给你：脚本不会替你置位，所以"今天想少做一点"仍然可以不点；也不会因为未达标就禁止进入下一阶段。

三条使用约束 决定这套系统能不能跑通

前提：每天按量背满、不跳天。只要满足这个前提，词 → 读 → 完形的链路是成立的（按理想路径模拟：完形 12 套的复现词 100% 落在当天累计应学里； 阅读与完形的复现词表已按当前词库重新校准：80 篇 / 套共 1809 个复现词次，100% 落在当天累计应学里，且 100% 在该篇正文中真实出现）。它是"按进度兑现"的设计，不是"自适应"的设计。
  1. 不能拖词量，落后先补词再往下读。targetNew() 会因复习积压把新词降到 22 / 26，连欠 3 天直接变 0； 而阅读和完形只看日历 dayNum() 解锁，既不检查你背没背，也不会等你。宁可停一天只清复习、不进新内容， 也别在词没补完的情况下往后读。补齐后链路自动恢复。
  2. 阅读和完形按天预设词表，不跟随实际掌握。每篇 / 每套写死了一组"该天应该已学过"的复现词，出题时不查询你的 seen 记录。 一旦拖了进度，就会出现"标称已学、实际没背过"的词，系统既不提醒也不补。
  3. 遇到没学过的词是正常的，靠上下文和中文提示处理。正文不是封闭词表，完形选项大量依赖词形变化与基础词兜底。 这些词库外的词答错不会自动进背词队列（markWeak() 被 seen 挡住），觉得重要就在进度页手动导入自定义词表。
另外，完成判定是手动点、不校验完成度：打卡本身不检查正确率或完成量。系统给了客观进度提示，但是否算完成由你决定—— 别把"点亮 55 天"当成"过关了"。
